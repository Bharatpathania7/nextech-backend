# 🏥 Health Referral System - Backend

A scalable healthcare referral management backend developed during a healthcare innovation hackathon to improve hospital-to-hospital patient referrals and healthcare resource visibility.

The system provides secure REST APIs for authentication, referral processing, hospital resource management, and healthcare workflow coordination.

---

# 🏆 Hackathon Project

Developed as part of a healthcare-focused hackathon aimed at solving challenges in patient referral management and healthcare resource accessibility.

### Problem Statement

Healthcare providers often struggle to identify suitable hospitals for patient referrals due to fragmented communication, limited visibility into available resources, and manual coordination processes.

### Solution

The Health Referral System provides a centralized API-driven platform that enables healthcare organizations to manage hospital resources, process referrals, and improve coordination between healthcare providers.

# 🚀 Project Highlights

* Designed and implemented **20+ REST APIs** for authentication, referral management, hospital administration, and resource tracking.
